# 审查常见盲区形态

`blind-spots.md` 是逐项提问清单；这里记录为什么这些动作存在。

- 审了显式入口，隐式调用链的同一操作没有保护。
- 根目录默认参数通过；显式路径或嵌套仓库时实际作用位置变了。
- 只查路径/格式，正文身份、schema 版本仍可伪造。
- 审了一个 mutation 入口的并发与锁残留，另一个入口完全绕开。
- mock、当前快照或文本检查被夸大成真实依赖、历史状态或运行时行为。

## 交接常见假绿灯

- 服务端直连探针通过，被当成客户端实际参数路径已验证。
- 35 条断言打印通过，但命令始终不退出；断言通过不等于资源已清理。
- 只回退配置，没回退被断言保护的条件；测试仍绿，目标分支一次也没执行。
- `git push` 成功输出被当成远端状态；应以 `git ls-remote` 核目标 SHA。
- 「全部修完」没有枚举，实际只关了一部分 finding。

它们提示可能漏什么，不构成对当前批次已覆盖的证明。
