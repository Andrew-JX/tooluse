# 判据常见假绿灯

主文只保留检查动作；以下形态用于卡住时定位漏洞。

- **限定词漂移**：判据和评测都写「本周 N 次」，真实客户端却默认请求近 30 天；所有测试都绿，产品仍错。
- **恒真阈值**：旧实现耗尽 120 秒，判据写「130 秒内快速失败」；无论实现做什么都通过。
- **范围污染**：判据写「本任务涉及的文件」，上一批未提交的 447 行 CSS 也被算进本批。
- **错误层级**：service 单测通过，被报告成 HTTP 契约已覆盖；用户路径实际上没跑过。
- **同义断言**：`expect(add(a,b)).toBe(a+b)` 与实现共用同一推导，不能发现错误。

这些是设计判据时的反例，不是新的判据或授权来源。
