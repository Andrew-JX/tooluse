# C1 · 任务收尾

任务完成、暂停或需要同步时使用。时间上限 5 分钟。

先结账，再总结：

1. 每条未决逐条标为已解决、仍未解决或已放弃，并给证据或原因。
2. 每条假设逐条标为已验证、已推翻或仍未验证；被推翻时回看原先写的后果是否发生。
3. 对每项产出只使用：
   - `已改`
   - `已测（范围：X）`
   - `已验证完成（判据：Y）`
4. 列出新增未决、条件式风险和需要哪个角色给出的决定、资源、授权或时间。

AI 参与实现时，收尾前还要写清：改动涉及的数据流或控制流、当前证据为什么支持结论、验证覆盖范围与未覆盖边界、出问题时的第一排查点。写不出来时，不得标为“已验证完成”，只能标“已改”或“已测”。

每条结论说明它对下一步意味着什么：是否可复用、成立条件、验证或推翻了哪条假设、完成判据是否变化。输出完整事实层并标注「草稿·未发送」；不替用户决定汇报顺序或删减事实。
