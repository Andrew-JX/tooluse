# B · 卡住

连续约 90 分钟没有产生新证据，或新发现会改变工期、范围时使用。时间上限 2 分钟。

```text
任务号：T<n>
卡点：<一句技术症状>
试过什么：<做法 → 结果 → 证据或无证据>
当前假设与哪条证据矛盾：
```

必须选择并写下截止点：

- 继续：到具体时间或再试 N 次必须停。
- 换路：写明另一条具体路径。
- 求助：写明角色和一个可用“是/否”或“A/B”回答的问题。

新增内容使用 `[未决 T<n>-#k]`；风险写成 `若 <条件>，则 <后果>，触发信号是 <可观察事实>`。说不出假设与证据的矛盾时，直接报告“尚未形成可检验实验”，不要替用户编造。
