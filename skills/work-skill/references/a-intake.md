# A · 接任务

时间上限 3 分钟。先由用户自己写，不让模型替用户理解任务。

## 输入

```text
任务号：T<n>
任务类型：<不含专有名词>
我自己的话复述：
交付物形态：
谁验收（角色）：
一句可证伪的完成判据：
```

## 补齐

- `[假设 T<n>-=1] 假设 <X>；若 X 不成立，则 <Y>`
- `[不懂·技术] <可以自行查证的问题> → 预计多久`
- `[不懂·领域] <无法从公开技术资料得到的问题> → 必须问哪个角色`
- `[未决 T<n>-#1] <谁在等什么>`；为空时说明为什么为空。

检查完成判据能否被证伪；检查每条领域不懂是否转成假设或确认问题。需要询问他人时，只生成三句话以内、只问最贵一到两个不确定项的「草稿·未发送」。
